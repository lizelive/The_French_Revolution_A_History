# Example Output

This directory contains sample output generated by `convert_gutenberg.py` to demonstrate the structure and format of the converted markdown files.

## Directory Structure

The converter organizes chapters into a hierarchical folder structure:

```
examples/
└── [volume_number]_[volume_name]/
    └── [book_number]_[book_name]/
        └── [chapter_number]_[chapter_name].md
```

For example:
- `01_the_bastille/01_death_of_louis_xv/01_louis_the_well_beloved.md`
- `01_the_bastille/02_the_paper_age/01_astraea_redux.md`

## File Format

Each markdown file contains:
1. **Chapter Title** (H1 heading)
2. **Chapter Content** (paragraphs with preserved formatting)
3. **Footnotes Section** (if the chapter references any footnotes)

### Example Chapter

See [01_louis_the_well_beloved.md](01_the_bastille/01_death_of_louis_xv/01_louis_the_well_beloved.md) for a full example with:
- Italic formatting (e.g., *Bien-aime*)
- Bold formatting (e.g., **Thirty other years**)
- Footnote references (e.g., [1], [2])
- Footnotes section at the end
